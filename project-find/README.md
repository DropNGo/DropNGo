# Project Find — Auto Research MVP

Erste unabhängige Auto-Research-Schicht innerhalb des DropNGo-Repositories.

## Produktidee
Der Nutzer schreibt eine natürliche Anfrage statt zehn Filter zu bedienen. Project Find zerlegt sie in Kriterien, prüft Plausibilität, findet passende und beinahe passende Fahrzeuge und erklärt die Entscheidung.

## Aktuell
- Natural-language Anfrage
- Kriterienextraktion
- Budget-/Marktrealitäts-Hinweis
- Ranking und Near-Matches
- mobile Oberfläche
- klare Kennzeichnung von Demo-Angeboten
